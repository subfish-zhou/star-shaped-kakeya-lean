以下是基于所给文稿和允许预备知识对星形 Kakeya 下界研究史的独立复述与分析：

### 1. 从 $\pi/98$ 到 $1/10$ 的主要机制变化

1.  **覆盖估计的去损（从 $\pi/98$ 到 $\pi/56$ 系列）**：改变的对象是圆周区间的覆盖选择机制 [E2][E4]。此前受限于丢弃部分区间并抽取互不相交子族所引入的“因子 3”损失 [E2]；下一步的证明义务是利用包住并集的开集连通分支，直接控制同心放大后的外长度 [E4]。此阶段中 $100\pi/5599$ 属于固定机制下的参数微调 [E6][E7]。
2.  **内外相加的付款解耦（到 $131\pi/6250$）**：改变的对象是计算结构，从“多类估计取最大值”变为“可测球内、球外分别付款相加” [N1]。此前的限制是不同估计无法直接叠加；下一步的证明义务是利用分割等式 $m^*(E) = m^*(E\cap D) + m^*(E\setminus D)$，并控制球外三角形部分与径向扇形重叠时的付款不重复 [N1]。
3.  **多段径向分配（到 $q\pi$ 与 $C_{pair,64}$）**：改变的对象是针方向的追踪维度，引入了最近最远距离及星形三角形必占的径向薄片 [N3]。此前局限于单一分界或粗糙的内外二分；下一步的证明义务是建立径向安排表，证明从有限的方向类别划分到任意无向方向选针的几何连接 [N3][N4][N8]。此阶段的 $1717/25000$、$7/100$ 等为参数或阈值调整 [N4][N5]，而 $C_{pair,64}$ 引入了近配对类的拆分与有理包围 [N9]。
4.  **加权测度与容量约束（到 $0.082812...$）**：改变的对象是物理集合上的权重分配 [N10]。此前的限制是类似 $0.09755$ 的候选方案因不同输出共享同一“端点—高度”来源而导致容量超支，判定为 BLOCKED [F1]；下一步的证明义务是引入加权测度 $d\nu = \min(r,1) dr d\theta$ 且限制总权重不超过 1 [N10]，并利用分段凹性控制连续参数穿越网格的事件 [N16]。此处的七行三系数展示属于表示简化，非数值突破 [A0][T1]。
5.  **双端点利用与低方向分支拆分（到 $1/10$）**：改变的对象是对低方向类（高度 $\le 1/5$）的几何挖掘 [T6]。此前的限制是低方向类无法从共享终端获得足够付款而成为瓶颈 [N14]；下一步的证明义务是将低方向类拆为 B、U 两类，为 B 类在物理圆上恢复出两个相反的理想锚点，并对 U 类在特定径向区间利用 $M+N \ge 1$ 予以补偿，最后通过互补权重 $\lambda$ 与 $1-\lambda$ 消除分类对积分系数的影响 [T6][T7]。

### 2. U 类声称的评估与径向付款分析

该声称**不成立**。
虽然 U 类的近端点半径 $N < 2/5$ 且线段满足 $M+N \ge 1$，迫使其远端点必须伸到 $3/5$ 以外（即 $M > 3/5$） [T6]，但这只改善了内侧截面的估计，付款并不会跑到 $3/5$ 以外 [T6]。

根据文稿，实际积分的**三段径向范围及各段估计**如下 [T6]：
1.  **$0 < r < 1/5$**：使用 $W(V)$ 的额外锚点估计，给完整权重。
2.  **$1/5 \le r < 7/20$**：使用 $W(V)$ 的普通远端估计，给完整权重。
3.  **$7/20 \le r < 1/2$**：使用 $W(U)$ 的更强远端估计（取权重 $\lambda$）与 $W(V)$ 的普通远端估计（取权重 $1-\lambda$）的结合。

**为何第一条锚点式虽对 $r < 2/5$ 有效，却没有在整个范围满价加入总账？**
因为锚点式的角截面估计值 $|S_r(V)| \ge k(r)(|V|+|B|)$ 中，收缩因子 $k(r) = \min\{2/3, (2/5-r)/(2/5+r)\}$ 随半径 $r$ 增大而衰减，当 $r \ge 2/5$ 时 $k(r) \le 0$（无有效正向付款）[T6]。此外，在 $1/5$ 以后的区间，必须控制不同估计所使用的物理材料重叠（如 $W(U) \subset W(V)$），如果不采用 complementary weights（如 $\lambda$ 与 $1-\lambda$）或转换为普通远端估计，就会违反总权重不超过 1 的容量限制 [T6]。

### 3. 双方向标签与 B 类的理想锚点

*   **不能把弧长加倍。** 即使两个方向标签分别只指向一个唯一来源，但这两个标签所对应的真实圆弧在物理上可能重叠，甚至只是同一段底弧被标记了两次 [T6]。如果在没有排除物理重叠的情况下直接加倍，会违反来源容量限制（账单总额超出了付款人的实际余额）[F1][T6]。
*   **B 类的两个理想锚点“给了什么，没给什么”**：
    *   **给了**：同一个无向方向在周长为 $2\pi$ 的物理圆上的**两个提升（一正一反）**，从而在 $r < 2/5$ 时能为合格的方向类提供多一倍的锚点长度，增强了截面下界 [T6]。
    *   **没有给**：在周长为 $\pi$ 的无向方向圆上的两个不同方向 [T6]；也没有给无需控制延伸长度就能直接相加的真实圆弧 [T6]。

### 4. 瓶颈、近似替代与 PL 反例分析

*   **小数差不全是几何提升**：$q\pi$ 与 $C_{pair,64}$ 之间的小数差不全是新近配对几何带来的。文稿指出，冻结表的瓶颈仍是未改动的第 49 类，且此处换用了更精细的超越函数包围，故不能把小数差全算作几何收益 [N9]。
*   **定位活动瓶颈**：通过平衡两个相互竞争的约束。例如在高度阈值 $H$ 的分析中，降低 $H$ 会增强低高度估计，但会削弱容易分支（三角形仅保 $H/2$），通过寻找两者的平衡有理参数点来定位瓶颈 [N12][N13]。
*   **0.0828125 无法替代 v2 精确下限**：因为 0.0828125 是浮点近似，而可靠的 v2 下限是精确有理安全下限 $\ge 0.082812499999972190$ [N15]。
*   **PL 失败不推翻 IL**：PL（逐半径配对估计）虽然被真实的连续单位针族反例否定，但该反例否定的是 PL 这种逐点断言，并不否定跨半径补偿的积分不等式 IL，更不否定全局 $1/10$ 结论 [T6][T8][T9]。
